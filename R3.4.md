# R3.4 — Strength calculator

## Tool
`tools/tarkovtool-strength-calc.html` + `js/strength-calc.js`

## Features
- Level 0–51 → approx yellow/red overweight kg (planning model)
- Stim checkboxes: SJ1 +20, Meldonin +10, …
- Preset: 21 + SJ1 + Meldonin → temporary elite (51)
- Table of thresholds; current level highlighted

## Notes
Weight curves are **approximate** — BSG patches change numbers. M.U.L.E. is capacity, not skill levels.
