# Changelog

## [R3.21] — 2026-10-24 — «Глобальное улучшение UX»

### Исправлено

- ПНВ: таблица показывается после загрузки; распознавание ночного видения не зависит от одного-единственного поля API.
- Броня и плиты: диалоги совместимости открываются через `showModal()` с fallback для старых браузеров.
- Карточка предмета: исправлены ссылки на задания, крафты, бартер и убежище; учтён выбранный режим PvE/PvP.
- Престижинатор: исправлена область видимости функций, демонстрационные данные отключены по умолчанию, ошибки загрузки отображаются явно.
- Укладка: визуальная сетка, поиск и множественный выбор контейнеров, поворот предметов, настраиваемый размер поля и понятный список неразмещённых предметов.

### Улучшено

- Добавлен режим инспектора предметов: кнопка на странице, `Alt+I` для включения/выключения; двойной клик по предмету быстро открывает карточку.
- Центральное разрешение названий и изображений предметов, включая стандартный вид оружия через default preset.
- Табличные инструменты могут получать иконку из общего каталога даже при использовании облегчённой модели строки.
- Карточки и варианты предметов получили идентификаторы для вызова инспектора там, где это безопасно.
- Добавлена UX-контрактная проверка наиболее хрупких интеграций R3.21.

### Проверки

- Статическая целостность HTML/JS и локальных ссылок.
- Контракты инструментария и профиля.
- Контракты доменных модулей.
- Архитектурная проверка каталога.
- Синтаксическая проверка всех JS-файлов через Node.js.
- Проверка UX-контрактов R3.21.

Формат близок к [Keep a Changelog](https://keepachangelog.com/). Версии проекта — по смыслу релизов Tarkov Tools (см. roadmap), не обязательно strict semver npm.
