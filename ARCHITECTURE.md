# Architecture

Tarkov Tools — статичный сайт в браузере. Страницы инструментов открываются отдельно или в iframe хаба. Общие скрипты подключаются явно в HTML.

## Слои

| Слой | Ответственность |
|------|-----------------|
| `core/` | API и кэш, storage, schema, i18n, poll, live runtime, item/weapon domain, общая UI-обвязка |
| `hub/` | Каталог, настройки, уведомления, оболочка и lifetime iframe |
| `tools/` | `tarkovtool-*.html` + meta JSON |
| `js/` | Логика конкретного инструмента |
| `locales/` | Переводы |
| `assets/icons/` | Иконки каталога |

Плоская раскладка `tools/*.html` — текущая норма. Перенос в `tools/<id>/index.html` — отдельная миграция, не требование lint.

## Поток данных

```text
tool page → TarkovAPI → json.tarkov.dev
                ↓
         кэш (память / tt:api:*)
                ↓
     TarkovItems / domain → UI инструмента

TarkovStorage (tt:*) ← настройки, tool data, poll meta
TarkovPoll / LiveRuntime ← live-расписание
hub ← catalog.js (codegen из meta) + iframe tools
```

## Обязательная граница данных

Страницы используют `TarkovAPI.items/tasks/traders/maps/hideout/crafts/barters`, которые возвращают коллекции одного формата. Разбор внешних envelope, проверка формы коллекции, идентичности записей и разрешение подписей принадлежат `TarkovData`. `getJson/request` — транспорт для `core/`, его вызовы из инструментов запрещены архитектурным lint.

`TarkovData` хранит сущности по **типу + ID + режиму + языку**. ID остаётся ключом связи, а не подписью. Предметы, существующие только для квеста, индексируются из `tasks.questItems` отдельно от обычного каталога. Не найденная ссылка возвращает `resolve(...).resolved === false`, читаемую подпись и сохранённый ID; `status()` различает idle/loading/ready/empty/error и сообщает о недостающих названиях. Это не подмена ошибки успешным пустым ответом.

У каждого слоя один владелец:

| Задача | Владелец | Инструмент |
|---|---|---|
| Сеть, кеш, объединение одинаковых запросов | `TarkovAPI` | Запрашивает именованную коллекцию |
| Структура коллекций, имена и ссылки, область режима/языка | `TarkovData` | Получает сущность или разрешает ссылку |
| Пользовательские короткие имена и поиск | `TarkovNames` | Вызывает `display`, без локального fallback |
| Выбор изображения, включая штатную сборку оружия | `TarkovItemMedia` | Использует общую проекцию |
| Адрес назначения сущности | `TarkovNav.entityHref(type, id)` | Передаёт тип и ID, без своей сборки URL |
| Профиль, фильтры, синхронизация и объединение событий | `TarkovProfile` | Подписывается через `bindRefresh` |
| Хранение документов и миграции | `TarkovStorage` / `TarkovSchema` | Не обращается к localStorage напрямую |
| Алерты, доступность, формулы, live-расписание | Существующие Alerts / Content / domain / Poll | Использует соответствующий сервис |

Транспортные ответы, реестр и данные потребителя не разделяют изменяемые вложенные объекты. Изменение строки одним инструментом не меняет общий каталог. Запоздалый старый ответ не перезаписывает свежий кеш или реестр. `TarkovData.latest()` предоставляет транзакцию загрузки, которую общая таблица проверяет перед публикацией результата: версия, режим и язык должны оставаться актуальными.

`data → names → item-media` подключаются явно и синхронно перед остальным кодом страницы. Поздняя загрузка этих обязательных зависимостей через shell не используется. `scripts/sync-core-deps.py` синхронизирует этот префикс; lint отклоняет отсутствие зависимостей, обход нормализованного API и локальные копии алгоритма имени.

Это общий контракт данных и инфраструктуры для всех страниц, а не универсальная проверка игровых формул. Специализированные вычисления остаются в domain-модулях; пользовательские сценарии и браузерные регрессии по-прежнему проверяют их интеграцию. Контрактные тесты `scripts/data-contract-test.cjs` проверяют гарантии общей границы независимо от числа инструментов и запускаются в CI.

## Правила владения

- Сеть и кэш API — только `tarkov-api.js`
- `localStorage` — только `tarkov-storage.js`
- Формулы предметов/оружия — domain-модули, не копии в `js/`
- Расписание poll id — `TarkovPoll`; под хабом огоньки/тики — LiveRuntime
- `hub/catalog.js` не правится руками: `python scripts/build-catalog.py`
- Meta инструмента — JSON в `#tarkovtool-meta` на странице
