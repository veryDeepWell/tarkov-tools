# R3.3 — Pure rating

## Domain `scoreItems`
- **score / pureScore** = quality×0.85 + load×0.15  
- **metaScore** = accessibility + value (price) — not in base sort score  
- components still expose access/value for optional columns

## Helmets
`helmetMountBonus` — slots matching NVG/thermal/light/laser (+ mount) up to +30% quality factor.

## gun-rating.js
Base **score**: ergo, recoil, rpm, slots, mod pool, ammo **variety** (not price).  
**metaScore**: cheap gun + cheap ammo (column only).  
Filter maxPrice still works for listing, not for ranking formula.
