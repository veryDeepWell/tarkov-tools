# Устранение неполадок

## Белый экран / страница не грузится

1. Откройте консоль (F12): ошибки JS, блокировка скриптов, mixed content.
2. Запускайте через `http://localhost`, не через `file://`, если API не отвечает.
3. Проверьте, что JavaScript включён.

## Пустой каталог в хабе

1. Сгенерируйте каталог: `python scripts/build-catalog.py`
2. Убедитесь, что в репозитории есть актуальный `hub/catalog.js` (или результат генерации, который подключает хаб).
3. Жёсткое обновление страницы (cache bypass).

## Сбросились настройки и закрепы

Данные живут в `localStorage` этого браузера и origin. Очистка данных сайта, другой браузер или другой профиль = пустое состояние. Имеет смысл периодически экспортировать настройки из хаба.

## Нет уведомлений

1. Разрешение уведомлений для origin в браузере.
2. Настройки звука/уведомлений в хабе (global mute, per-tool mute).
3. Для live-инструментов: опрос действительно запущен, вкладка/хаб не выгружены политикой браузера.

## Нет звука

Системная громкость, mute в хабе, mute типа события или конкретного инструмента. В iframe звук обычно играет сторона хаба после `Notify`.

## Price Track / Restock не обновляются

1. Консоль: 403/429/сеть до json.tarkov.dev.
2. Интервал опроса и флаг «запущено».
3. В хабе live-расписание ведёт LiveRuntime; не должно быть второго своего `setInterval` на тот же poll id.

## `TarkovStorage is not defined` / нет core

Страница инструмента должна подключать скрипты из `core/` в порядке, как у соседних тулзов (см. CONTRACT.md). Открытие «голого» HTML без путей к `../core/` сломает зависимости. Блокировщики скриптов тоже могут вырезать файлы.

## Ошибки контракта в CI

```bash
python scripts/lint-architecture.py
bash scripts/tool-contract-check.sh
bash scripts/domain-contract-check.sh
```

Частые причины: прямой `fetch` или `localStorage` в `tools/`, ручной edit `hub/catalog.js`, рассинхрон meta и каталога.

## Карта: нет меток / неверные позиции

1. Загрузились ли `map-data-all.js` и файлы в `tools/map-assets/`.
2. Выбрана ли нужная локация и этаж (метки с других этажей скрываются).
3. Для части локаций фон — схема, не полноценный тайлсет; маркеры всё равно из данных API.

## Сброс

В консоли на origin сайта:

```js
localStorage.clear();
location.reload();
```

Либо сброс из настроек хаба, если есть. Экспорт перед сбросом сохранит ключи.
