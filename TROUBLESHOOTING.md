# 🔧 Troubleshooting — Устранение проблем

## 🚨 Общие проблемы

### ❌ "Не загрузилась страница" / "Белый экран"

**Причины:**
- Браузер не поддерживает необходимые API
- Отключено JavaScript или cookies
- Проблемы с HTTPS (смешанный контент)

**Решения:**
1. Проверьте консоль браузера (F12 → Console):
   - `javascript:` — ошибки JS
   - `tarkov.dev` — доступ запрещён CORS
   
2. Обновите браузер до последней версии:
   - Chrome/Edge 90+
   - Firefox 88+
   
3. Попробуйте в другом браузере (например, Firefox вместо Chrome)

---

### ❌ "Каталог пустой" / "Инструменты не показываются"

**Причины:**
- `catalog.json` не сгенерирован или устарел
- Ошибки при генерации каталога

**Решения:**
1. Запустите генерацию:
   ```bash
   python scripts/build-catalog.py
   ```

2. Проверьте консоль на ошибки в `scripts/`

3. Перезагрузите страницу после генерации

---

### ❌ "Настройки сбросились" / "Мои закрепления исчезли"

**Причины:**
- Очистка localStorage браузера
- Смена устройства/браузера

**Решения:**
1. Настройки сохраняются в `localStorage` вашего браузера
2. Используйте один браузер для всех сессий
3. Если нужно перенести настройки — экспортируйте через инструменты (если доступны)

---

## 🔔 Проблемы с уведомлениями

### ❌ "Уведомления не приходят"

**Причины:**
- Отключены в настройках браузера
- Браузер блокирует уведомления для страницы

**Решения:**
1. Разрешите уведомления в Chrome/Edge:
   - Нажмите на иконку замка → **Настройки сайта** → **Уведомления** → **Разрешить**
   
2. Проверьте настройки в хабе:
   - Settings → Notifications
   - Убедитесь, что уведомления включены

3. Отключите энергосбережение для фоновых вкладок (особенно важно на Mac)

---

### ❌ "Нет звукового сигнала"

**Причины:**
- Звук отключён в браузере/ОС
- Неправильный выбор файла звука

**Решения:**
1. Проверьте общий звук в системе
2. Настройте громкость для уведомлений в хабе
3. Загрузите свой звуковой файл (если поддерживается)

---

## 🛠️ Проблемы с инструментами

### ❌ "Price Track не обновляется"

**Причины:**
- API `tarkov.dev` недоступен или медленный
- Установлен слишком большой интервал опроса

**Решения:**
1. Проверьте консоль браузера на ошибки CORS/429 (rate limit)
2. Уменьшите интервал опроса в настройках Price Track
3. Перезагрузите страницу

---

### ❌ "Restock Alert не срабатывает"

**Причины:**
- Торговец не обновляется по API
- Предмет не поддерживается текущей версией API

**Решения:**
1. Проверьте официальный API документацию `tarkov.dev`
2. Добавьте предметы, которые поддерживаются
3. Убедитесь, что инструмент работает офлайн (не только через хабе)

---

### ❌ "Ошибки в консоли: 'TarkovStorage' не определён"

**Причины:**
- Страница загружается без hub скриптов
- Конфликт с другим расширением браузера

**Решения:**
1. Откройте страницу через `tarkovtool-hub.html` (не напрямую)
2. Отключите блокировщики рекламы/скриптов для этой страницы
3. Обновите страницу

---

## 🌐 Проблемы с локализацией

### ❌ "Язык не переключается"

**Причины:**
- Браузер определяет неправильный язык
- JS cookie заблокирован

**Решения:**
1. Проверьте язык в настройках браузера
2. Попробуйте вручную установить языковой пакет (если есть)
3. Отключите блокировку cookies и перезагрузите страницу

---

## 📱 Проблемы на мобильных устройствах

### ❌ "Инструмент не адаптируется под экран"

**Причины:**
- Мобильный браузер не поддерживает viewport meta tag
- Устаревший мобильный браузер

**Решения:**
1. Используйте последнюю версию Chrome/Safari
2. Откройте через мобильную версию сайта (мобильные)

## 🧹 Очистка и сброс

### 🔧 Полная очистка настроек

Используйте для полного сброса:

1. **В браузере:**
   ```bash
   # Открыть страницу в incognito/приватном режиме
   # Это очистит все данные за 60-90 дней
   ```

2. **Через инструменты хабе:**
   - Settings → Reset All
   - Подтвердите сброс

3. **Манипуляции через консоль (F12):**
   ```javascript
   // Очистить localStorage для сайта
   localStorage.clear();
   location.reload();
   ```

## 📋 Проверка работы системы

Перед открытием инструмента выполните:

```bash
# 1. Проверка интернета
ping tarkov.dev  # (если работает пинг)

# 2. Проверка API
curl https://tarkov.dev/api/health  # (пример)

# 3. Открытие в браузере с консолью (F12)
```

Если видите ошибки:
- `CORS` — проблема доступа к ресурсу
- `404` — страница не найдена
- `500` — ошибка на сервере API
