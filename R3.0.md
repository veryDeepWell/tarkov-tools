# R3.0 — Item Graph + deep-link

## core/tarkov-item-graph.js

```js
TarkovItemGraph.build({ items, tasks, crafts, barters? })
TarkovItemGraph.card(itemId)   // { id, item, name, links }
TarkovItemGraph.links(itemId)
TarkovItemGraph.href(itemId)   // tarkovtool-item-card.html?item=…
TarkovItemGraph.get(itemId)
```

Индексы R3.0: `questsUsing`, `questsRewarding`, `craftsAsInput`, `craftsAsProduct`, `soldBy`  
(+ пустые заготовки family/ammo/barters для R3.1+)

**Не копирует** payload предмета в индексах связей — только ID и метаданные связи.

## tools/tarkovtool-item-card.html + js/item-card.js

- Загрузка items+tasks+crafts → `build`
- Поиск / `?item=` → секции: soldBy, квесты, крафты
- `window.render` + `bindGameMode`
- Auto-load если в URL есть `item`

## tools/tarkovtool-item-use.html

Редирект на `item-card` (legacy `?id=` → `?item=`).

## Deep-link out

- `ammo` / `mods`: имя → `TarkovItemGraph.href(id)` (нужен script graph в HTML)
- HTML: ammo, mods, crafts, quests подключают graph
