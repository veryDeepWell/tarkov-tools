# Руководство пользователя

## Что это

Tarkov Tools — набор страниц-утилит для Escape from Tarkov в браузере. Центр — хаб (`tarkovtool-hub.html`): каталог, настройки, уведомления, мини-табы.

Данные предметов и рынка приходят из сети (API). Ваши настройки и списки хранятся только в этом браузере.

## Запуск

1. Откройте `tarkovtool-hub.html` через локальный HTTP-сервер или GitHub Pages.
2. Выберите инструмент в каталоге или из закреплений.
3. При необходимости смените язык и звук в настройках хаба.

Прямое открытие `file://` может ограничить запросы к API.

## Типы инструментов

**Статические** — загрузили данные, посчитали, показали (каталоги, калькуляторы, карта).

**Живые** — периодический опрос (Price Track, Price Alarm, Restock и т.п.). Интервал настраивается в инструменте; в хабе статус виден на мини-табе.

## Хаб

- Поиск и категории каталога
- Закрепление часто используемых инструментов
- Скрытие категорий/инструментов (настройки каталога)
- Панель уведомлений
- Мини-табы: компактный вид live-инструмента внутри хаба

Открытие мини-таба не обязано само запускать опрос — старт задаётся логикой инструмента и Poll.

## Уведомления и звук

Инструменты шлют события через общий `Notify`. Хаб показывает тост и может воспроизвести звук.

В настройках:

- общий mute / громкость
- mute по типу события
- mute по конкретному инструменту

Браузер может отдельно блокировать уведомления страницы — это настраивается в разрешениях сайта.

## Настройки

Сохраняются в `localStorage` (канонические ключи с префиксом `tt:`). Смена браузера или очистка данных сайта сбрасывает состояние.

Экспорт/импорт всех `tt:`-ключей — из настроек хаба (если пункт доступен в вашей сборке): JSON с метаданными схемы экспорта.

## Карта

Инструмент «Карта» — локальный просмотрщик: SVG/схемы локаций, маркеры из API, фильтры, этажи где есть. Это не iframe tarkov.dev.

Точность координат и покрытие этажей по локациям различаются; часть карт (например новые) может быть со схемой-заглушкой при рабочих маркерах.

## Локализация

RU и EN через `locales/`. Переключение — в настройках / i18n хаба. Названия предметов идут через цепочку имён (игра / API / пользовательские short name), не всегда совпадают с вики один в один.

## Во время игры

Удобный сценарий: хаб на втором мониторе или в окне рядом, live-инструменты на мини-табах, статику открывать по необходимости. Модификаций клиента игры проект не требует и не делает.

## Ограничения

- Нужен доступ к API для свежих цен и справочников (пока нет offline-снимка из будущего патча)
- Прогресс персонажа в игре сайт сам не читает — только то, что вы ввели или отметили локально
- Мобильная вёрстка части инструментов ограничена; сложные тулзы рассчитаны на десктоп
