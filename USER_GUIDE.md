# 📚 Руководство пользователя Tarkov Tools

## Что это за проект?

**Tarkov Tools** — набор браузерных утилит для игры **Escape from Tarkov**. Все инструменты работают прямо в браузере без установки, модификации игры или сложной настройки.

### Основные возможности

- 🔍 **Каталоги** — поиск предметов, оружия, брони
- 💰 **Отслеживание цен** — графики и уведомления об изменениях
- 🚫 **Алёрты на пополнение** — отслеживайте торговцев и мусорки
- 🎨 **Генераторы loadout** — рандомные сборки, дроп-сборки
- 🗺️ **Интерактивные карты** — 12 локаций с точками интереса
- ⚔️ **База боссов** — характеристики и слабые места

## 🚀 Быстрый старт

### Первый запуск

Просто откройте в браузере:

```bash
# В корневой папке проекта
tarkovtool-hub.html
```

Или используйте локальный сервер:

```bash
python -m http.server 8000
# или
npx serve .
```

Откройте `http://localhost:8000/tarkovtool-hub.html` в браузере.

### Что вы увидите?

- 📁 **Каталог инструментов** — слева список доступных утилит
- 🔍 **Поиск** — найдите нужный инструмент по названию
- 🎯 **Закрепленные инструменты** — ваши часто используемые под рукой

## 📖 Работа с инструментами

### Статические инструменты (каталоги)

Эти инструменты работают моментально без фоновых опросов:

1. Откройте нужный инструмент из каталога
2. Ищите, фильтруйте, сортируйте
3. Сохраните результат как картинку/текст (если поддерживается)

**Примеры:**
- [Barters](./tools/tarkovtool-barter-live.html) — бартеры у торговцев
- [Flea Catalog](./tools/tarkovtool-flea-catalog.html) — все предметы с ценами
- [Armor Catalog](./tools/tarkovtool-armor-catalog.html) — броня и пластины

### Живые инструменты (background monitoring)

Эти инструменты периодически опрашивают сервер:

1. Закрепите инструмент в хабе (или открывайте напрямую)
2. Настройте параметры (целевая цена, предметы для отслеживания)
3. Получайте уведомления об изменениях

**Примеры:**
- [Price Track](./tools/tarkovtool-price-track.html) — график цены в реальном времени
- [Restock Alert](./tools/tarkovtool-restock.html) — алёрты на пополнение у торговцев

## 🔔 Уведомления

### Как работают

Уведомления появляются:
- В углу браузера (toast notifications)
- В виде звукового сигнала (опционально)
- С мини-табами (для закрепленных инструментов)

### Настройка уведомлений

1. Откройте **Settings** в хабе
2. Нажмите **Notifications Settings**
3. Настройте:
   - 🔇 Общий громкость
   - 🎵 Звук для каждого типа (успех, ошибка, предупреждение)
   - ⏱️ Интервал показа (чтобы уведомления не сливались)

### Мини-табы (mini-tabs)

Закрепленные инструменты получают мини-таб в хаб:

1. Закрепите инструмент (нажмите пин + в инструменте)
2. Мини-таб появляется в хабе с активным индикатором
1. Закрепите инструмент (нажмите пин + в инструменте)
2. Мини-таб появляется в хабе с активным индикатором
3. Нажмите на таб — инструмент откроется в полноразмерном режиме

## ⚙️ Настройки

### Общие настройки (в хабе)

Все настройки сохраняются автоматически:

| Настройка | Где изменить |
|-----------|-------------|
| 🔇 Звук | Settings → Notifications |
| 🎨 Цвет | Settings → Appearance → Accent Color |
| 📦 Показать скрытые инструменты | Settings → Catalog → Show Hidden Tools |
| 📌 Закрепить инструмент | Кнопка "Pin" в инструменте |

### Сброс настроек

Нажмите **Reset All** в настройках, чтобы очистить всё и начать заново.

## 🔍 Поиск и фильтрация

### Поиск инструментов

Используйте поиск в хабе (значок 🔍):

- Введите название инструмента
- Фильтруйте по категориям (Weapons, Armor, Barters...)
- Используйте горячие клавиши (если поддерживаются)

### Фильтрация каталога

Большинство инструментов имеют фильтры:

1. **Категории** — выберите нужную группу
2. **Сортировка** — от низкой к высокой цене и наоборот
3. **Статус** — свободные/занятые слоты, редкость предметов

## 🔐 Безопасность и приватность

### Что делает Tarkov Tools

✅ Читает данные из **tarkov.dev API**
✅ Записывает настройки в **localStorage браузера**
✅ Показывает уведомления в интерфейсе

### Чего НЕ делает

❌ НЕ отправляет ваши данные третьим лицам
❌ НЕ требует доступ к файлам игры
❌ НЕ использует сторонние трекеры/аналитику

## 🎮 Использование во время игры

Многие инструменты работают как **встраиваемые виджеты** в хабе-iframe:

1. Откройте нужную игру
2. Нажмите на хаб в углу экрана
3. Выбирайте инструменты через каталог или закрепленные
4. Мини-табы всегда доступны

Примеры сценариев:

- **Проверка цен** перед вылетом — откройте Price Track в мини-табе
- **Генерация loadout** — быстро создавайте сборки через Random Loadout
- **Поиск боссов** — проверяйте статус боссов перед выездом на рейд

## ❓ FAQ — Часто задаваемые вопросы

### Q: Нужен ли интернет для работы инструментов?

**A:** Для загрузки данных да. Некоторые инструменты работают офлайн (если данные закэшены).

### Q: Где мои настройки?

**A:** Все сохраняются в браузере (localStorage). Доступны только вам на этом устройстве.

### Q: Почему не приходят уведомления?

**A:** Проверьте:
- 🔇 Настройки звука/уведомлений
- 🚫 Разрешения браузера для уведомлений
- 🔋 Режим энергосбережения (может отключать фоновые процессы)

### Q: Можно ли использовать на Android/iOS?

**A:** Да! Просто откройте ссылку в мобильном браузере. Интерфейс адаптируется под экраны.

### Q: Поддерживаются ли старые браузеры?

**A:** Минимальные требования см. в README.md (Chrome 90+, Firefox 88+).

## 🎓 Для начинающих

### Как открыть конкретный инструмент?

- Через **каталог инструментов** (справа/слева в хабе)
- Из **закрепленных** (если ранее закреплен)
- Прямой ссылкой из README.md/каталога JSON

### Как закрепить инструмент?

1. Откройте нужный инструмент
2. Нажмите кнопку **Pin / Закрепить** (обычно вверху страницы)
3. Инструмент переместится в закрепленный раздел
4. Мини-таб появится в хабе для быстрого доступа

### Как скрыть категорию?

1. Откройте **Settings → Catalog**
2. Уберите галочку у нужной категории
3. Инструменты этой категории исчезнут из списка (но останутся доступными по прямой ссылке)

## 🎯 Продвинутые функции

### Настройка интервала опроса

Для живых инструментов можно изменить частоту опроса:

1. В настройках инструмента найдите **Polling Interval**
2. Установите нужное значение (в минутах)
3. Меньше = чаще обновления, но больше нагрузка на сеть

### Экспорт данных

Некоторые инструменты поддерживают экспорт:

- Сохраните как картинку (Print/Скриншот)
- Скопируйте JSON/XML в буфер обмена
- Сохраните таблицу как CSV (если доступно)
