# Описание инструментов Tarkov Tools

Источник списка: `hub/catalog.js` (60 инструментов). Карта добавлена отдельно — в этом снимке каталога её ещё может не быть.

Формат на каждый тул:
- **Название** — как в каталоге
- **Файл** — `tools/...`
- **Тип** — static | live
- **Категория**
- **Кратко** — 1 строка для карточки хаба / meta `description`
- **Подробно** — для help / README инструмента

---

## Барахолка (`flea`)

### Price track
- **Файл:** `tarkovtool-price-track.html`
- **Тип:** live
- **Кратко:** История цены на барахолке, фоновые снимки, таймер до следующего опроса.
- **Подробно:** Выбираете предмет и интервал. Инструмент периодически сохраняет цену (и связанные поля с API), рисует историю, показывает countdown. Работает в хабе через TarkovPoll / LiveRuntime. Нужен для ручного анализа динамики, не для мгновенного «купи/продай».

### Сирена цен (Price Alarm)
- **Файл:** `tarkovtool-price-alarm.html`
- **Тип:** live
- **Кратко:** Уведомление, когда цена или число офферов пересекает заданный порог.
- **Подробно:** Правила вида «цена ниже X» / «офферов больше N». При срабатывании — Notify + звук (с учётом mute). Несколько правил на разные предметы. Не заменяет Price Track: сирена реагирует на порог, track копит историю.

### Таймер рестока
- **Файл:** `tarkovtool-restock.html`
- **Тип:** live
- **Кратко:** Обновление ассортимента торговцев, сигнал, история срабатываний.
- **Подробно:** Следит за появлением или доступностью выбранных позиций у торговцев. Пилик/уведомление при рестоке. История нужна, чтобы не пропустить окно закупки.

### Бартер (ручной)
- **Файл:** `tarkovtool-barter-calc.html`
- **Тип:** static
- **Кратко:** Калькулятор выгоды бартера: компоненты и комиссия барахолки.
- **Подробно:** Вручную или полуавтоматом задаёте вход и выход, учитываете налог flea при продаже/закупке. Для разовых прикидок без привязки к «живому» прайсу.

### Бартер (live)
- **Файл:** `tarkovtool-barter-live.html`
- **Тип:** static
- **Кратко:** Бартеры с ценами барахолки через API, пресеты связок.
- **Подробно:** Подтягивает актуальные цены ингредиентов и результата. Пресеты частых трейдов. Удобно проверить, жив ли ещё выгодный маршрут.

### Оптимизатор бартера
- **Файл:** `tarkovtool-barter-opt.html`
- **Тип:** static
- **Кратко:** Подбор бартера под бюджет; цены ингредиентов с рынка, не «флип-мечты».
- **Подробно:** Задаёте ограничения (бюджет, торговец, тип), получаете варианты с реальной стоимостью сбора. Цель — купить/собрать выгодно, а не нарисовать идеальный спред.

### Трейдер-флип
- **Файл:** `tarkovtool-trader-flip.html`
- **Тип:** static
- **Кратко:** Покупка у торговца → продажа на барахолке.
- **Подробно:** Список позиций, где цена торговца ниже flea с учётом налога. Быстрый скан «что слить после рестока».

### Стример-флип
- **Файл:** `tarkovtool-streamer-flip.html`
- **Тип:** static
- **Кратко:** Ивент- и стример-предметы, потенциал флипа.
- **Подробно:** Узкий срез под temporary/event loot и похожие позиции, где цена гуляет сильнее обычного каталога.

### Список покупок
- **Файл:** `tarkovtool-shopping-list.html`
- **Тип:** static
- **Кратко:** Вишлист после рестока: патроны, мед, флип; копирование имён.
- **Подробно:** Чеклист закупки. Копирование short/display name в буфер для быстрого поиска в игре или на барахолке.

## Лоадаут (`loadout`)

### Патроны
- **Файл:** `tarkovtool-ammo.html`
- **Тип:** static
- **Кратко:** Пробитие по калибрам; подробные статы по наведению.
- **Подробно:** Таблица/фильтр патронов: урон, пробитие, бронебойность, фраг, цена. Сравнение внутри калибра. База для выбора БК, не строитель магазина.

### Броня
- **Файл:** `tarkovtool-armor.html`
- **Тип:** static
- **Кратко:** Рейтинг брони по классу, зонам и плитам, без упора в цену.
- **Подробно:** Фокус на защите и зонах покрытия. Совместимость с плитами — через domain, не локальная копипаста формул. Цена вторична (см. отдельный мета-рейтинг в roadmap).

### Плиты
- **Файл:** `tarkovtool-plates.html`
- **Тип:** static
- **Кратко:** Класс, вес, прочность, стоимость ремонта.
- **Подробно:** Справочник бронеплит и эффективность относительно класса/веса. Связка с бронёй двусторонняя (что куда встаёт).

### Моды
- **Файл:** `tarkovtool-mods.html`
- **Тип:** static
- **Кратко:** Рейтинг обвесов по статам и совместимости.
- **Подробно:** Обвесы не в контексте полного дерева слотов пушки, а как каталог: эрго, отдача, вес, куда встаёт. Для глубокой сборки — gun-builder / gun-budget.

### Магазины
- **Файл:** `tarkovtool-mags.html`
- **Тип:** static
- **Кратко:** Магазины по калибрам: ёмкость, эрга, отдача.
- **Подробно:** Фильтр по калибру/платформе, сравнение ёмкости и штрафов. Дополнение к патронам и модам.

### Прицелы
- **Файл:** `tarkovtool-scopes.html`
- **Тип:** static
- **Кратко:** Кратность, ПНВ, community tier.
- **Подробно:** Оптика и коллиматоры: кратность, поля, ночные режимы, эвристический/community рейтинг. Не конфиг всего оружия.

### ПНВ
- **Файл:** `tarkovtool-nvg.html`
- **Тип:** static
- **Кратко:** Intensity, noise, diffuse, эвристический score.
- **Подробно:** Ночное зрение как отдельный класс предметов: читаемые статы из API и сводный score для сравнения.

### Наушники
- **Файл:** `tarkovtool-headphones.html`
- **Тип:** static
- **Кратко:** Характеристики из API, рейтинг цена/слух, фильтры.
- **Подробно:** Сравнение гарнитур по слышимости/глушению и цене. Для выбора «что надеть в рейд», не симулятор акустики.

### Сборка оружия
- **Файл:** `tarkovtool-gun-builder.html`
- **Тип:** static
- **Кратко:** Схема слотов (дуло←приклад), зоны, зум, Auto Build.
- **Подробно:** Конструктор оружия: установка обвесов, совместимость, статы сборки. Auto Build и визуальная схема. Сохранение/обмен билдов — развитие в roadmap Arsenal.

### Сборка за N ₽
- **Файл:** `tarkovtool-gun-budget.html`
- **Тип:** static
- **Кратко:** Сборка оружия в рамках бюджета.
- **Подробно:** Ограничение по цене при подборе обвесов. Связан с gun-builder; не полный лоадаут персонажа.

### Рейтинг оружия
- **Файл:** `tarkovtool-gun-rating.html`
- **Тип:** static
- **Кратко:** Оружие по цене, патронам, модам, эрго/отдаче и доступности.
- **Подробно:** Сводный рейтинг стволов с учётом обвесов/БК и того, насколько реально достать. Не замена полной сборки в gun-builder.

### Шлемы
- **Файл:** `tarkovtool-helmets.html`
- **Тип:** static
- **Кратко:** Класс, зоны, штрафы; ricochet / blunt / слоты по наведению.
- **Подробно:** Сравнение шлемов отдельно от бронежилетов. Рикошет, тупой урон, слоты под гарнитуру/НВ — в подсказках и таблице.

### Лоадаут-билдер
- **Файл:** `tarkovtool-loadout-builder.html`
- **Тип:** static
- **Кратко:** Сборка лоадаута с пресетами.
- **Подробно:** Оружие, броня, рюкзак, разгрузка, мед и т.д. Сохранение/загрузка наборов. Будущий единый формат с gun builder — в roadmap.

### Лоадаут за N ₽
- **Файл:** `tarkovtool-loadout-budget.html`
- **Тип:** static
- **Кратко:** Полный лоадаут под бюджет (может быть заглушкой).
- **Подробно:** Если страница ещё stub — в meta/каталоге это отражено. Идея: уложиться в сумму на весь кит.

### Рандомный лоадаут
- **Файл:** `tarkovtool-random-loadout.html`
- **Тип:** static
- **Кратко:** Случайный комплект, раскладка как на персонаже.
- **Подробно:** Генерация для челленджей и разнообразия. Не оптимизатор меты.

### Дрип по цветам
- **Файл:** `tarkovtool-drip.html`
- **Тип:** static
- **Кратко:** Экип по цветам (песок, чёрный, MC…) + score статов.
- **Подробно:** Фильтр внешнего вида и лёгкий score защиты/удобства. Мода/ролеплей + не полный отрыв от статов.

### Дрип-лоадаут
- **Файл:** `tarkovtool-drip-loadout.html`
- **Тип:** static
- **Кратко:** Стили и цвета, paperdoll-раскладка.
- **Подробно:** Сборка внешнего вида на «кукле». Дополнение к drip по цветам.

### Дрип-билдер (моды)
- **Файл:** `tarkovtool-drip-builder.html`
- **Тип:** static
- **Кратко:** Поиск модов оружия по цветам (заглушка возможна).
- **Подробно:** Цветовой подбор обвесов. Если stub — не ожидать полный gunsmith.

## Убежище (`hideout`)

### Крафты убежища
- **Файл:** `tarkovtool-crafts.html`
- **Тип:** static
- **Кратко:** ROI крафтов: цены, время, выгода.
- **Подробно:** Что крафтить имеет смысл при текущих ценах, сколько ждать, какие станции нужны.

### Биткоин-ферма
- **Файл:** `tarkovtool-btc-farm.html`
- **Тип:** static
- **Кратко:** ROI майнинга: GPU, топливо, солнце, Hideout Management.
- **Подробно:** Оценка дохода фермы при разных конфигурациях и навыков. Не игровой клиент — калькулятор.

### Ящики
- **Файл:** `tarkovtool-cases.html`
- **Тип:** static
- **Кратко:** Кейсы и контейнеры: что влезает, сетка, поиск.
- **Подробно:** Вместимость и ограничения по типам предметов. Для планирования схрона.

### Разгрузки и рюкзаки
- **Файл:** `tarkovtool-containers.html`
- **Тип:** static
- **Кратко:** Слоты, вес, сегменты — рейтинг контейнеров на теле.
- **Подробно:** Сравнение разгрузок/рюкзаков по полезному объёму и штрафам.

### Схрон (hideout)
- **Файл:** `tarkovtool-hideout.html`
- **Тип:** static
- **Кратко:** Станции убежища, требования, апгрейды.
- **Подробно:** Карта прогресса hideout: что нужно для уровня станции, зависимости. Не таймер реального строительства в игре.

### Качатель Hideout Management
- **Файл:** `tarkovtool-hideout-mgmt.html`
- **Тип:** static
- **Кратко:** Какой крафт крутить на станции за минимум ₽ за цикл скилла.
- **Подробно:** Оптимизация прокачки Hideout Management: дешёвые циклы крафта по станциям, не общий ROI продажи на барахолке.

## Квесты (`quests`)

### Квесты · карты
- **Файл:** `tarkovtool-quests.html`
- **Тип:** static
- **Кратко:** Квесты с реальными картами, цели по шагам, требования.
- **Подробно:** Глоссарий заданий: где выполняется, что сдать, что открывает. «Любая локация» по возможности заменяется конкретными картами из данных.

### Квест-предметы
- **Файл:** `tarkovtool-quest-items.html`
- **Тип:** static
- **Кратко:** FIR и квестовые предметы, трекинг.
- **Подробно:** Что нужно найти/оставить FIR, для каких заданий. Локальные галочки прогресса — до профиля ЧВК из roadmap.

### Квест-чиз
- **Файл:** `tarkovtool-quest-cheese.html`
- **Тип:** static
- **Кратко:** Что скрафтить или взять с других квестов под нужный квест/предмет.
- **Подробно:** Обходные пути: крафт, награды других заданий, бартер вместо прямого лута.

### Боссы и гуны
- **Файл:** `tarkovtool-bosses.html`
- **Тип:** static
- **Кратко:** Шансы боссов, таймеры/карты, гуны.
- **Подробно:** Справочник боссов и связанных точек. Не путать с полной «базой боссов» из будущего Maps & Combat.

### Чек-лист рейда
- **Файл:** `tarkovtool-raid-checklist.html`
- **Тип:** static
- **Кратко:** Сборки под карты, DnD-список; «В РЕЙД» сбрасывает галочки по таймеру.
- **Подробно:** Перед выходом отмечаете взятое. Режим рейда через ~20 минут сбрасывает чеки, чтобы список не врал после возврата.

## Мед / еда (`med`)

### Стимуляторы
- **Файл:** `tarkovtool-stims.html`
- **Тип:** static
- **Кратко:** Инъекторы: бой, выносливость, отхил, вес; эффекты из API.
- **Подробно:** Сравнение стимов по баффам и цене/весу. Для выбора «что взять в карман».

### Комбо стимуляторов
- **Файл:** `tarkovtool-stim-combos.html`
- **Тип:** static
- **Кратко:** Связки (Meldonin+SJ1, SJ6+Trimadol, Propital+MULE и др.).
- **Подробно:** Готовые комбинации с иконками и копированием. Не симулятор всех взаимодействий баффов.

### Аптечки
- **Файл:** `tarkovtool-medkits.html`
- **Тип:** static
- **Кратко:** HP на клетку, скорость применения, ₽/HP; аптечки и таблетки.
- **Подробно:** Эффективность хила относительно слота и цены. Фильтры по типу урона/использования — по реализации страницы.

### Еда и вода
- **Файл:** `tarkovtool-food.html`
- **Тип:** static
- **Кратко:** Energy, hydration, цена, ₽/очко.
- **Подробно:** Еда и напитки как ресурс рейда, не «рецепты готовки».

## Утилиты (`util`)

### Опыт
- **Файл:** `tarkovtool-xp.html`
- **Тип:** static
- **Кратко:** Источники XP, множители, киллы, таблица уровней.
- **Подробно:** Калькулятор и справочник прогресса уровня ЧВК.

### Починка
- **Файл:** `tarkovtool-repair.html`
- **Тип:** static
- **Кратко:** Ремонт брони и оружия: качество, цена, материалы, влияние скиллов.
- **Подробно:** Оценка стоимости доведения до нужной прочности у торговца/через наборы.

### Престиж-оптимизатор
- **Файл:** `tarkovtool-prestige.html`
- **Тип:** static
- **Кратко:** Что унести в престиж: квесты, капитал, плотность слотов.
- **Подробно:** Помощь в выборе переносимого. Дальше — «Престижинатор» с окном предметов и «Собрать престиж» (roadmap).

### Сезоны
- **Файл:** `tarkovtool-seasons.html`
- **Тип:** static
- **Кратко:** История сезонов: модификаторы, доки, даты.
- **Подробно:** Справка по вайпам/сезонам и правилам, не лайв-трекер текущего онлайна.

### Боевой пропуск
- **Файл:** `tarkovtool-battle-pass.html`
- **Тип:** static
- **Кратко:** Трекинг BP (в т.ч. Kord Breach): страницы, награды.
- **Подробно:** Локальный прогресс по страницам BP. Привязка к конкретному сезону/ивенту — как в данных инструмента.

### Челлендж
- **Файл:** `tarkovtool-challenge.html`
- **Тип:** static
- **Кратко:** Рандом карты, задания, лоадаута; свои правила; локальный XP.
- **Подробно:** Генератор ограничений для разнообразия рейдов. Очки только локальные.

### Марафон
- **Файл:** `tarkovtool-marathon.html`
- **Тип:** static
- **Кратко:** Цепочки переходов между локациями: расходники, XP, лут, выходы.
- **Подробно:** Планирование multi-map забега. Позже стыкуется с картой и квест-маршрутами.

### Хитбоксы и урон
- **Файл:** `tarkovtool-hitboxes.html`
- **Тип:** static
- **Кратко:** HP, хитбоксы, перенос урона, симулятор попаданий.
- **Подробно:** Справочник механики урона + простой симулятор. Интерактивное 3D/вращение — развитие в roadmap.

## Прочее (`other`)

### My Tarkov
- **Файл:** `tarkovtool-my-tarkov.html`
- **Тип:** static
- **Кратко:** Дашборд локального состояния: убежище, квесты, алерты.
- **Подробно:** Заготовка центра персонажа. Полноценный профиль ЧВК — патч 1.1; сейчас опирается на то, что уже пишется в storage.

### Desk
- **Файл:** `tarkovtool-desk.html`
- **Тип:** static
- **Кратко:** Несколько инструментов рядом, общее состояние.
- **Подробно:** Рабочий стол из виджетов. Не замена хабу, а доп. раскладка.

### Круг культистов
- **Файл:** `tarkovtool-cultist.html`
- **Тип:** static
- **Кратко:** Base value 350k/400k; цена через торговцев, flea, бартер-цепочки.
- **Подробно:** Подбор сдачи в круг с оценкой стоимости набора.

### Ключи
- **Файл:** `tarkovtool-keys.html`
- **Тип:** static
- **Кратко:** Ключи по локациям, цена, рейтинг.
- **Подробно:** Что открывает, где актуально, стоит ли таскать/покупать.

### Короткие имена
- **Файл:** `tarkovtool-shortname.html`
- **Тип:** static
- **Кратко:** Поиск по short name + цены торговца/flea.
- **Подробно:** Быстрый резолв «как это называется в поиске игры» и ориентир по цене.

### Локализатор
- **Файл:** `tarkovtool-lang-search.html`
- **Тип:** static
- **Кратко:** Поиск предметов и квестов по именам в выбранных языках API.
- **Подробно:** Когда знаете название на другом языке или наоборот.

### Лут ₽/слот
- **Файл:** `tarkovtool-loot-slot.html`
- **Тип:** static
- **Кратко:** Цена за клетку инвентаря; flea и торговец; метка квеста.
- **Подробно:** Приоритет лута в рейде: что тащить, если места мало.

### Что с предметом
- **Файл:** `tarkovtool-item-use.html`
- **Тип:** static
- **Кратко:** Продажа, крафт, убежище, квесты, бартер по одному предмету.
- **Подробно:** Точка входа «зачем мне этот лут». Зародыш полной карточки предмета (1.2).

### Сравнение

### Скиллы + чизы
- **Файл:** `tarkovtool-skills.html`
