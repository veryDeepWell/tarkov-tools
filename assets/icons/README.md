# Custom tool icons

Drop icons here using the **icon id** from the hub catalog.

| Example file | Tool |
|--------------|------|
| `price-track.svg` | Динамика цен |
| `restock.png` | Таймер рестока |
| `cultist.webp` | Круг культистов |

Supported extensions: `.svg`, `.png`, `.webp` (tried in that order via `TarkovIcons`).

Or set `"iconUrl": "assets/icons/my-art.png"` on a catalog entry in `tarkov-hub-app.js`.

Until a file exists, the hub shows the emoji fallback.
