# Tarkov Tools 1.1 — Профиль ЧВК

## Общее

Профиль ЧВК становится единым источником персональных данных для остальных тулзов.

При создании профиля пользователь задаёт имя персонажа. К профилю привязываются уровень, навыки, УЛ торговцев, выполненные квесты и престиж. Глобальные данные вроде истории Price Tracker остаются общими.

Профиль должен иметь приоритет над стандартными и ранее введёнными значениями.

## Изменения

Добавить события изменения профиля: повышение уровня, изменение УЛ торговца, выполнение квеста, открытие нового контента.

Связать инструменты через общий storage и контекст навигации. Например: предмет → квесты → граф → бартер → цены.

Добавить импорт/экспорт профиля и сохранение престижа.

## Новое

### Мой Тарков

Полноценный центр ЧВК: уровень, прогресс, навыки, УЛ торговцев, доступный контент, задания, новые открытия и список того, чем сейчас можно заниматься.

### Что я могу сделать?

На основе профиля показывать весь доступный прямо сейчас контент: квесты, новые УЛ, предметы, бартеры, крафты, улучшения схрона и прочее. После изменения профиля показывать именно новые открытия.

## Реализация

Ввести единый `PMCProfile` и storage-слой. Изменения профиля проходят через него и генерируют события. Инструменты читают состояние из профиля, а не создают собственные копии прогресса.

Навигация передаёт ID сущности между инструментами, чтобы пользователь не вводил один и тот же предмет или квест повторно.
