# Tarkov Tools 2.1 — Offline Mode

## Общее

Сделать локальную копию Tarkov Tools пригодной для работы без интернета после первоначальной загрузки данных.

Пользователь скачивает исходный код и разворачивает сайт на устройстве. В настройках появляется Offline Mode.

## Новое

При подготовке оффлайн-режима скачать и сохранить статические данные:
- предметы;
- характеристики;
- зависимости;
- квесты;
- карты;
- торговцев;
- другие справочники.

После этого инструменты работают с локальным snapshot.

## Ограничения

Функции, которым нужны актуальные сетевые данные, должны быть отключены или явно показывать ограничение. Главный пример — получение текущих цен барахолки.

Профиль ЧВК полностью локален.

## Реализация

Ввести абстракцию `DataProvider`:

`OnlineDataProvider` → API

`OfflineDataProvider` → локальный snapshot.

Инструменты не должны знать, откуда пришли данные.

Snapshot должен иметь версию схемы. Обновление:
1. определить версию;
2. загрузить новый набор;
3. проверить целостность;
4. заменить локальную версию;
5. переключить инструменты на новый snapshot.

Расширить импорт/экспорт для профилей, ЧВК, сайта, билдов, лоадаутов и игровых результатов.

## Результат

Пользователь может получить автономную копию Tarkov Tools, которая предоставляет почти всю статическую информацию без доступа к интернету.
