# Tarkov Tools 1.3 — Arsenal Workshop

## Общее

Закончить Gun Builder и Loadout Builder и дать им единый формат сохранения.

Добавить экспорт в изображение для билдов и лоадаутов.

## Реворки

### Gun Builder

Полноценный конструктор оружия:
- дерево слотов;
- установка модификаций;
- проверка совместимости;
- сохранение;
- импорт/экспорт;
- сравнение;
- экспорт в изображение;
- передача оружия в Loadout Builder.

### Loadout Builder

Полноценная сборка ЧВК:
- модифицированное оружие;
- магазины;
- броня;
- разгрузка;
- шлем;
- рюкзак;
- прочее снаряжение.

Добавить сохранение, импорт/экспорт, экспорт в изображение и получение оружия из Gun Builder.

## Новое

### Случайный ган

Пользователь задаёт направление — болтовка, пулемёт, AR-15, конкретная платформа — и получает конкретное оружие. Это не генератор лоадаута.

### Мутация билда

Взять существующий билд и случайно заменить одну или несколько частей. Режимы — от одной замены до полного превращения билда в ебанину. Результат всегда должен оставаться валидным.

### Слияние билдов

Взять два билда и собрать валидный гибрид из деталей обоих.

## Реализация

Gun Builder и Loadout Builder используют единый сериализуемый формат: `itemId + slotId + installedItemId + nested attachments`.

Мутация и слияние должны использовать существующий валидатор совместимости, а не дублировать правила установки.

## Результат

Оружейные инструменты превращаются в единую систему конструирования, сохранения и обмена билдами.
