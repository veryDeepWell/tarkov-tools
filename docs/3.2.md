# Tarkov Tools 3.2 — Mobile

## Общее

Подготовить интерфейс к полноценной работе на телефонах.

## Изменения

Переработать навигацию, таблицы, карточки, карты, Gun Builder, Loadout Builder, Quest Graph, мини-игры и Oracle.

Сложные desktop-интерфейсы не должны просто уменьшаться до нечитаемого размера.

Для карт:
- pinch-to-zoom;
- перемещение;
- выбор маркеров;
- компактные фильтры.

Для Gun Builder дерево слотов превращается в последовательный мобильный интерфейс.

## Реализация

Создать общую систему responsive layout и переносить инструменты группами. Не делать отдельную мобильную копию логики и данных.

## Результат

Tarkov Tools становится пригоден для полноценного использования с телефона.
