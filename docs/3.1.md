# Tarkov Tools 3.1 — Integrated App

## Общее

Собрать все подсистемы в единое приложение:
- профиль;
- база данных;
- карты;
- аналитика;
- билдеры;
- игровой слой;
- multiplayer;
- offline provider;
- Oracle.

## Изменения

У всех инструментов единый механизм открытия, передачи контекста, получения сущностей, сохранения состояния и экспорта.

Навигация должна позволять проходить цепочки без повторного поиска:

Item Analyzer → квест → Quest Graph → маршрут → карта → БТР → предмет.

## UI

Сделать общий игровой стиль с сохранением читаемости.

Унифицировать:
- иконки;
- панели;
- карточки;
- уведомления;
- контекстные действия;
- состояния загрузки и ошибки.

## Результат

Tarkov Tools воспринимается как единое приложение, а не каталог независимых HTML-страниц.
