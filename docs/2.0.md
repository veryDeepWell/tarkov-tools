# Tarkov Tools 2.0 — Local Multiplayer

Это крупный системный патч.

## Общее

Игровой слой из 1.5 получает multiplayer-режим.

Архитектура: браузер хоста хранит состояние игры, остальные браузеры подключаются напрямую по P2P через WebRTC. `RTCDataChannel` предназначен для двусторонней передачи произвольных данных между браузерами и защищает передачу через DTLS.

## Главное ограничение

Не использовать внешний игровой backend.

Для первого соединения WebRTC требуется signaling, но он нужен только для обмена техническими данными. Его можно заменить ручным обменом кодами/offer-answer, чтобы не иметь внешнего сервиса вообще.

В LAN-режиме соединение должно работать напрямую внутри локальной сети.

## Новое

### Создание комнаты

Хост нажимает «Создать комнату», получает код/данные приглашения и передаёт их друзьям.

Игрок вводит код, устанавливает P2P-соединение и получает состояние от хоста.

### Host-authoritative

Хост хранит игроков, состояние игры, RNG, правила, ставки/очки и результаты.

Клиенты отправляют действия вроде `BET_PLACED` или `ANSWER_SELECTED`. Хост проверяет их, меняет состояние и рассылает результат.

### Multiplayer Core

Отдельный слой отвечает за:
- host/join;
- соединения;
- отправку и получение сообщений;
- синхронизацию;
- disconnect/reconnect;
- состояние игроков.

Игры не должны знать о WebRTC.

## Казино Барахольщика

Полноценное локальное казино:
- автоматы;
- blackjack;
- рулетка;
- другие режимы.

Раз в день выдаётся игровой капитал. Он не имеет реальной ценности. Всё хранится локально; возможность вручную изменить localStorage не является проблемой.

## Результат

Главный сценарий: **Создать комнату → дать друзьям код → играть.**

Игровое состояние находится у хоста, а не на сервере сайта.
