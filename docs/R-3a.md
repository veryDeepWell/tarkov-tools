# Tarkov Tools R-3a — «Скелетный ключ» — Key Analyzer

## Связи

- Хаб: [[ROADMAP]]
- Продолжает: [[R-3]]
- Базируется на: [[R-2]], [[R-1]]

## Общее

Инструменты вокруг **ключей** с общим личным рейтингом и анализатором скрина ключницы.

## Архитектура рейтинга

| Слой | Назначение |
|------|------------|
| `data/keys-rating.json` | Источник: `ratings[id\|slug] → 1..100` (+ optional note) |
| `core/tarkov-keys-rating.js` | `load`, `getScore`, `getScoreOr`, `getMeta` |
| Тулы (keys, key-analyzer, …) | Только читают API, **не** дублируют формулу «дорого = хорошо» |

Пока JSON пустой — колонка Score показывает «—». Заполнение рейтинга — отдельный контент-пасс.

## Изменения (keys)

- Убраны кнопки **Стоимость** / **Рейтинг фарма** (не работали / рудимент).
- Убран смысл колонки **Тип**; квест остаётся флагом Quest.
- Колонка **Score** = личный рейтинг из `keys-rating`, не farm-формула.

## Новое

### Оценщик ключей (`tarkovtool-key-analyzer.html`)

1. Загрузка каталога keys + tasks.  
2. Скрин (drag/paste/file) → OCR (Tesseract по кнопке, CDN on-demand) или ручной текст.  
3. Сопоставление строк с каталогом.  
4. Таблица: score, flea, quest.  
5. Список квестов, затронутых ключами на скрине.  
6. Сумма flea по комплекту.

## Реализация

- R3a.0 (этот патч): rating module + keys UX + analyzer skeleton.  
- Далее: улучшение OCR/матчинга, пресеты контейнеров, связка с item-card `?item=`.

## Результат

Единый score ключей для всех key-тулов; оценщик скрина как вход в разбор ключницы.
