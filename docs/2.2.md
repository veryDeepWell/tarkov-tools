# Tarkov Tools 2.2 — Game Layer

## Общее

Превратить игровые функции в единую подсистему.

Игровой профиль и PMC-профиль не смешиваются: рекорды относятся к пользователю сайта, а прогресс ЧВК — к персонажу.

## Новое

### Достижения

Добавить официальные игровые и кастомные сайтовые достижения.

Автоматически проверять то, что возможно проверить. Для остальных использовать доверительную ручную отметку.

### Статистика

Хранить и показывать:
- рекорды;
- лучшие результаты;
- количество игр;
- статистику по отдельным мини-играм;
- результаты multiplayer.

### Казино Барахольщика

Закончить казино как полноценный игровой слой: капитал, рекорды и статистика работают через общий игровой API и остаются локальными.

## Изменения

Все мини-игры переводятся на единый формат результата:
- игра;
- версия правил;
- результат;
- очки;
- сложность;
- дата;
- профиль.

Это позволяет добавлять новые игры без переделки игровой инфраструктуры.

## Результат

Мини-игры становятся полноценной системой сайта, а не набором независимых страниц.
