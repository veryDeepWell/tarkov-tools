# Tarkov Tools 3.0 — Oracle

Один из самых больших патчей проекта.

## Общее

Оракул — универсальный интерфейс над всей базой Tarkov Tools.

Пользователь пишет естественный запрос:
- «Боссы развязки»
- «Самый слабый босс»
- «Крутой патрон на калаш»
- «Где найти LEDX»

Система должна понять смысл запроса и использовать существующие данные и инструменты.

## Архитектура

Нужна глобальная система тегов, покрывающая всю игру:
- тип сущности;
- принадлежность;
- оружейные платформы;
- боеприпасы;
- карты;
- боссы;
- торговцы;
- квесты;
- характеристики;
- доступность;
- связи;
- операции фильтрации и сортировки.

Критически важны приоритеты тегов.

«Крутой патрон на калаш» должен идти по цепочке `AK platform → ammo → meta-rating`, а не искать сначала все патроны и потом все оружие.

## Примеры

### «Боссы развязки»

`босс + развязка` → подходящие боссы.

### «Самый слабый босс»

`босс + слабый + самый` → выбрать боссов → сортировать по сложности → взять первый.

### «Крутой патрон на калаш»

`AK platform + ammo + quality` → определить боеприпасы платформы → сортировать по мета-рейтингу.

### «Где найти LEDX»

`where-find + item` → искать конкретные спавны.

Для редкого предмета выводить не весь общий медицинский лут, а релевантные источники: гарантированные спавны, редкие точки, куртки, медсумки и т. п.

## Реализация

Разделить систему на:

### Parser
Разбирает текст.

### Tag Resolver
Преобразует слова и синонимы в игровые теги.

### Relation Graph
Хранит связи сущностей.

### Query Planner
Определяет порядок фильтров и операций.

### Ranking
Сортирует результаты.

### Renderer
Передаёт результат существующему инструменту.

Оракул не должен дублировать существующие инструменты. Запрос карты использует карту, запрос карточки предмета — Item Analyzer, запрос маршрута — Квест-маршрут.

## Результат

Tarkov Tools превращается из набора инструментов в единую исследовательскую систему с естественным языковым интерфейсом.
