# Tarkov Tools 1.2 — Item Intelligence

## Общее

Сделать предмет полноценной точкой входа во всю связанную информацию сайта.

Цепочка должна работать в обе стороны: предмет → квесты → схрон → крафты → бартеры → торговцы → цены → связанные предметы.

## Изменения

### Анализатор предмета

Переработать в полноценную карточку предмета:
- характеристики;
- размер и вес;
- квесты;
- схрон;
- крафты;
- бартеры;
- контейнеры;
- торговцы;
- цены;
- ограничения барахолки;
- связанные предметы.

### Хитбоксы как ориентир

Продолжить принцип интерактивного представления: если данные можно покрутить, приблизить, выделить или исследовать визуально, предпочтительнее интерактивный интерфейс.

### Рейтинг

Убрать из обычного рейтинга цену, доступность и квестовые ограничения. Оставить характеристики самого предмета. Добавить фактор возможности установки фонаря/ПНВ на шлемы.

### Источники

Вынести источники в отдельный пункт хедера: вики, Reddit, комментарии разработчиков, YouTube, сайты и прочее.

## Новое

### Семейство предметов

Показывать связи вариантов одного предмета. Для оружейной платформы: платформа → версии → магазины → модификации → боеприпасы.

### Эффекты

Каталог баффов и дебаффов с описанием, влиянием, способом получения и длительностью.

### Случайный факт

Случайный факт из базы: количество квестов, бартеров, крафтов и других связей предмета, характеристики оружия, факты из истории игры.

## Реализация

Не хранить отдельные копии данных предмета. Карточка агрегирует существующие связи базы. Все переходы используют ID сущностей, а не отображаемые названия.

## Результат

Предмет становится полноценным узлом базы данных Tarkov Tools.
