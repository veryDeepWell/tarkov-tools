Общее - в инструменты на подобии плит, брони, шлемов и тому подобное, внести изменения в рейтинг, заставив считать его по всем параметрам (цена на барахолке, цена у торговца, УЛ торговца, закрыто за квестом, вес, размер самого предмета и так далее)

Квест-чиз - какие предметы для квеста можно скрафтить в убежке, какие можно получить за другие квесты. Поиск идет по квестам ИЛИ по предметам
Престиж-оптимизатор - какие предметы передать по престижу, чтобы без проблем закрыть первые квесты, получить капитал и тп.
Плиты - информация по починке плит сверху
Починка - расчет сколько нужно качать броники и уход за оружием (хз как вообше это сделать)
Ящики - кейсы игры, и что в них можно пихать. Выглядит это как сетка 3 предмета по X и до бесконечности вниз. Каждый предмет можно открыть, появиться меню где видно все предметы что туда можно поместить. Например для патронника будут все патроны. Разумеется, с поиском.

----

Рейтинг оружия - по цене / цене патронов / доступности патронов / количеству модов / цене модов / доступности модов. Короче по всем возможным метрикам, вообще всем.
Оптимизатор бартера - оптимизатор бартера для покупки предмета, а не перепродажи. Например вещевой THICC за LEDX, ставлю за 20 миллионов, инструмент смотрит сколько стоят предметы, и считает за сколько мне нужно их купить, чтобы уложиться в цену. При этом он оптимизирует, не будет показывать LEDX за 1 рубль, а примерно реальные цены
Марафон - скорее больше оптимизарот переходов. В интерфесе можно поочередно добавлять карты. Начать можно с любой карты (Например первой будет Лаборатория), но начиная со второй добавить можно только те, на которые есть переход с текущей крайней (В примере можно добавить только Улицы, потому что с Лаборатории есть переход только на Улицы), далее можно продолжать добавлять карты хоть до тепловой смерти вселенной (В примере после Улиц можно добавить Развязку, Лабораторию, Эпицентр...). Инструмент должен: 1) посчитать сколько примерно нужно еды / патронов / брони / гранат / медицины / расходников типа карт для лабы / денег для БТР и передачек; 2) посчитать множитель опыта (учитывай что множители недавно изменились); 3) вывести примерное количество ресурсов что найти в рейде (взять 20 SALEWA не получиться, поэтому нужно взять чуть-чуть, а остальное искать в рейде); 4) подсказать на какой карте и где стоит поискать ресурсы (Например на Развязке стоит проверить Kiba ради целых плит и патронов). Если список карт заканчивается на карте с выходом фаером и/или выходом такси инструмент это также отобразит как возможность свалить. Важно учитывать что Лабиринт и Ледокол так же являются валидными картами для перехода, пусть и будут конечными. Также супер режим: Марафон, за один рейд пройти все переходы с оптимизированным маршрутом чтобы не ходить по кругу.
Опыт - показывает за что дают опыт, множители опыта, а также калькулятор примерного опыта по киллам, ну так для галочки.
