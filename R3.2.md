# R3.2 — Family & weapon chain

## Graph `__v: 3`
- `family[itemId]` — siblings by normalizedName platform key
- `ammoFor` — gun↔ammo same caliber
- `magsFor` — gun↔mag by caliber; ammo→mag via allowedAmmo
- `modsFor` — mods sharing family key with a gun (heuristic)
- `weaponChain(id)` — capped lists

## Card UI
Секции: Семейство, Ammo / Mags / Mods — ссылки `?item=` на карточки.

## Limits
Эвристики, не полный compat-граф слотов (это gun-builder). Overrides JSON — позже.
