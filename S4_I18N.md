# S4 — i18n status / load / error / empty

## Канон

Shell уже подгружает `tarkov-i18n.js` → доступны `TarkovI18n.t` / `window.t`.

```js
function tt(key, params) {
  return TarkovI18n.t(key, params); // fallback: key
}
status.textContent = tt("common.loading");
status.textContent = tt("common.loadError", { message: e.message });
status.textContent = tt("common.empty");
```

`TarkovUI.statusSet(el, key, params, tone)` — опциональный хелпер.

## Locales (все 5 языков)

В `common` добавлено:

| key | смысл |
|-----|--------|
| `loading` | уже было |
| `loadingData` | «Загружаю данные…» |
| `loadError` | `Error: {message}` |
| `loadedOk` | «Загружено» |
| `loadedCount` | `Loaded: {count}` |
| `empty` | уже было |

## Патч JS (~23+ тулов)

Заменены типичные status-строки: Гружу… / Ошибка / Пусто / Loading / Тяну…

## Остаток (S4b — не блокер)

Сообщения с **русскими существительными и счётчиками**:
`Модов: N`, `Ключей: N`, `в рейде…`, UI-кнопки «Все / Сбросить».

Их надо либо:
- ключи `tool.<id>.ui.*` в locales, либо
- нейтральный `common.loadedCount`

Полный перевод всех UI-лейблов тулов — отдельный объём, не смешиваем с status-контрактом.
