# Инструменты Tarkov Tools v1.0 — Полное описание

## 🎯 Платформа

Tarkov Tools — набор браузерных утилит для **Escape from Tarkov** без модификаций игры и сборки. Всё работает в браузере через статический хостинг.

### Ключевые особенности:
- ✅ **0%** отправки данных за пределы клиента (все данные локально)
- 🌐 Поддержка 2 языков: Русский / English
- 🔊 Настраиваемая система уведомлений
- 📱 Адаптивный дизайн для мобильных устройств

### Типы инструментов:

| Тип | Описание | Обновление |
|------|----------|------------|
| **Живые** (Background) | Мониторинг рынка, цены | В реальном времени |
| **Статичные** (Reference) | Каталоги, справочная информация | При загрузке |
| **Виджеты** (Mini-tabs) | Компактные инструменты для хаба | По требованию |

## 🎯 Background Monitoring (Живые инструменты)

Эти инструменты работают в фоне и обновляются в реальном времени.

### 📈 Price Track
**URL:** [`tools/tarkovtool-price-track.html`](tools/tarkovtool-price-track.html)  
**Тип:** Живой инструмент  
**Функции:**
- Отслеживание цены предмета в реальном времени
- Графический график динамики цен
- Фильтр по торговым точкам (Traitors, Junker, Military, Snowback)
- История изменения цен с момента запуска мониторинга

### 🔔 Price Alarm  
**URL:** [`tools/tarkovtool-price-alarm.html`](tools/tarkovtool-price-alarm.html)  
**Тип:** Живой инструмент  
**Функции:**
- Установка целевой цены уведомления
- Аудио и push-уведомления при достижении цели
- Настройка чувствительности (±5%, ±10%, ±20%)
- Мульти-алермы для нескольких предметов

### 📦 Restock Alert  
**URL:** [`tools/tarkovtool-restock.html`](tools/tarkovtool-restock.html)  
**Тип:** Живой инструмент  
**Функции:**
- Мониторинг пополнения у торговцев (Junker, Snowback, Military)
- Отслеживание MULE спавна и пиковых часов
- История предыдущих ресток событий
- Таймер до следующего обновления
