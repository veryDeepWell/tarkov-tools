# v1 migration progress

Updated: 2026-09-21

## Rule

Always update this file after each migration batch, bug fix discovered during smoke, and browser validation pass. This file is the resumable work log; `v1fixes.txt` remains the architecture plan and acceptance criteria.

## Completed architecture slices

### Foundation

- Added `TarkovItems` repository/index boundary.
- Added `TarkovItemDomain` for item classification, armor/plate models, metrics, filtering and bidirectional armor/plate compatibility.
- Added `TarkovWeaponDomain` for weapon/mod slot normalization, reverse compatibility and mod projections.
- Added `TarkovStorage` browser persistence adapter.
- Updated `TarkovAPI` cache to use storage and clock seams.
- Added `TarkovItemViewModels` for pure armor/plate table projections.
- Shell loads shared storage, item domain, weapon domain and view-model dependencies.

### Migrated tools

- Armor and plates: shared classifier, projections, compatibility graph, repository and storage.
- Mods, compare and gun-builder: shared weapon compatibility boundary, repository and storage.
- Ammo, medkits, stims, stim-combos, NVG, food: normalized item repository and storage.
- Helmets, mags, scopes: normalized item repository and storage.
- Crafts, hideout, hideout-mgmt, barter-live: normalized item catalog repository and storage; recipes/hideout-specific endpoints remain behind `TarkovAPI.request` until endpoint repositories are introduced.
- Quest/requirements family (quests, quest-items, loot-slot, item-use, bosses, raid-checklist): normalized `TarkovAPI.tasks`/`maps`/`goonReports`/`crafts`/`hideout`/`items` endpoint repositories and `TarkovStorage`; no raw `TarkovAPI.request` or direct `localStorage` left in these tools. Quest locale fetches go through the single `TarkovAPI.getJson` boundary.
- Loadout/util family (loadout-builder, random-loadout, gun-budget, containers, keys): `TarkovAPI.items(mode)`/`tasks(mode)` endpoint repositories and `TarkovStorage` for presets/settings/game-mode; legacy `TarkovAPI.request` fallbacks removed; `tarkov-storage.js` include added to all five tool HTMLs. `loadout-budget` remains a stub page (no JS) - nothing to migrate.
- Full-sweep batches (batch 4): ammo, crafts, hideout, hideout-mgmt, drip, drip-loadout, compare, price-track, streamer-flip, trader-flip, shortname, skills, my-tarkov. All remaining tools now use `TarkovAPI` endpoint methods (`items`/`tasks`/`maps`/`crafts`/`hideout`/`barters`/`traders`/`goonReports`) and `TarkovStorage`; the `request` adapter is no longer used by any tool. Fixed a dead endpoint: `TarkovAPI.hideout` now calls `/hideout` (the old `/hideout/stations` path returned `Not found`).
